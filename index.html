§ 01

关于我

我是 时雨时猫，一个刚开始学编程的人。2026 年 8 月，我第一次打开终端，身边有个叫 Momo 的小伙伴陪着我，敲了人生第一条 git commit——当时完全不知道自己在干嘛，但那一天就是一切的开始。

从那以后就一直在瞎折腾：建仓库、搞崩东西、修好（大部分时候能修好）。弄明白一点就记一点。没想到这些随手记的东西，攒着攒着就成了本 Git + GitHub 指南——就是我第一天就想有人塞给我的那种说明书。还是乱，还是真，但真的有别的初学者说帮到他们了。如果你也在自己的坑里摸爬滚打，来打个招呼呗。

“每一次 commit，都像给当时的自己拍一张快照。”
