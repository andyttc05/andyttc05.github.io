About me

I’m Verno. August 2026 was when I first opened a terminal. With a little helper named Momo keeping me company, I typed git commit having no idea what it meant, and somehow that was the beginning.

Since then I’ve been fumbling through repos, breaking things, fixing them (mostly). I write down whatever sticks. At some point my messy notes turned into an actual Git + GitHub guide — the kind I wish someone had handed me on day one. Still messy. Still honest. But turns out other beginners find it useful too. If you’re in the middle of your own chaos, say hi.

“Every commit is a snapshot of a thought you almost forgot you had.”
